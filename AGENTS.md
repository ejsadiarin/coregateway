## Agent skills

### Issue tracker

Issues live as GitHub issues in `ejsadiarin/coregateway`; use the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` + `docs/adr/` at the repo root. Directories under `services/` are separate repos with their own `CONTEXT.md` and issues — read that repo's context before changing its code. See `docs/agents/domain.md`.
